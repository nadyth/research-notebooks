# Graph Attention Networks (GAT)

**Paper:** Petar Veličković, Guillem Cucurull, Arantxa Casanova, Adriana Romero, Pietro Liò, Yoshua Bengio. *Graph Attention Networks*. ICLR 2018. [arXiv:1710.10903](https://arxiv.org/abs/1710.10903)

**Kaggle:** [![Kaggle](https://kaggle.com/static/images/open-in-kaggle.svg)](https://www.kaggle.com/code/nadymsazad/graph-attention-networks-gat)

## Summary

Graph Attention Networks (GATs) by Veličković et al. introduced a novel graph neural network architecture that replaces the fixed, degree-based normalization of Graph Convolutional Networks (GCNs) with **learned attention weights** over each node's neighborhood. The core innovation is a **masked self-attention mechanism** applied to graph-structured data: for each node, the model computes attention coefficients between the node and each of its neighbors by feeding their concatenated (or summed) features through a shared learnable attention vector, followed by a LeakyReLU nonlinearity and a softmax over the neighborhood. These attention coefficients then replace GCN's fixed symmetric normalization, producing a weighted aggregation of neighbor features that is **data-driven and task-specific** rather than determined solely by graph topology. Stacking multiple GAT layers — with multi-head attention in the hidden layers (concatenating the outputs of K independent attention heads) and averaging in the output layer — yields node representations that achieve or match state-of-the-art results on four established benchmarks: Cora, Citeseer, Pubmed (transductive), and a protein-protein interaction dataset (inductive). The architecture is fully inductive (no need to know the full graph upfront), computationally efficient (linear in edges, parallelizable across node-neighbor pairs), and does not require any costly spectral eigendecomposition or matrix inversion.

### Core Idea

The key insight is that spectral graph convolutions (GCN) assign **fixed weights** to neighbors based solely on node degree — every neighbor contributes equally (after symmetric normalization), regardless of its actual relevance to the target node. GAT replaces this fixed scheme with a **learnable attention mechanism**: for node $i$ and neighbor $j$, the attention coefficient $e_{ij} = \text{LeakyReLU}(\mathbf{a}^T [\mathbf{W}\mathbf{h}_i \| \mathbf{W}\mathbf{h}_j])$ is computed from the transformed features of both nodes, then normalized via softmax over $i$'s neighborhood to get $\alpha_{ij} = \text{softmax}_j(e_{ij})$. The new representation is $\mathbf{h}'_i = \sigma(\sum_{j \in \mathcal{N}(i)} \alpha_{ij} \mathbf{W} \mathbf{h}_j)$. Multi-head attention runs $K$ independent attention mechanisms in parallel and concatenates (hidden layers) or averages (output layer) their outputs, stabilizing training and capturing different attention patterns. This formulation addresses all major shortcomings of spectral GNNs: no eigendecomposition needed, inductive learning is natural (attention weights are computed from features, not the global graph), and the model can assign **different importance to different neighbors** — a crucial capability for heterophilic graphs where not all neighbors are equally informative.

### Key Method Details

- **Linear transform first:** Each node feature $\mathbf{h}_i$ is projected by a shared weight matrix $\mathbf{W}$ ($F \to F'$) before attention is computed. This maps all nodes into a common representation space.
- **Attention mechanism:** The attention coefficient $e_{ij}$ is computed by concatenating the projected features of node $i$ and neighbor $j$, applying a learnable attention vector $\mathbf{a} \in \mathbb{R}^{2F'}$, and passing through LeakyReLU (negative slope 0.2). This is a single-layer attention — simple but effective.
- **Masked softmax:** The attention is **masked** — only neighbors of node $i$ (including itself, via self-loops added implicitly) participate in the softmax. Non-neighbors get $-\infty$ before softmax, yielding zero contribution.
- **Multi-head attention:** $K$ independent attention heads (each with its own $\mathbf{W}$ and $\mathbf{a}$) run in parallel. Hidden layers concatenate: $\mathbf{h}'_i = \|_{k=1}^{K} \sigma(\sum_j \alpha_{ij}^k \mathbf{W}^k \mathbf{h}_j)$. The output layer averages: $\mathbf{h}'_i = \sigma(\frac{1}{K}\sum_{k=1}^{K}\sum_j \alpha_{ij}^k \mathbf{W}^k \mathbf{h}_j)$.
- **Self-loops via attention:** Unlike GCN's explicit $A + I$, GAT includes each node in its own neighborhood implicitly — the attention mechanism computes $\alpha_{ii}$ just like any other $\alpha_{ij}$, so the node attends to its own features alongside neighbors.
- **Architecture:** Two-layer GAT for transductive tasks (Cora/Citeseer/Pubmed): first layer with $K=8$ heads and $F'=8$ output features per head (concatenated to 64), second layer with $K=1$ head and $C$ output classes (averaged, softmax). ELU activation in hidden layer, softmax in output.
- **Training:** Semi-supervised cross-entropy on labeled nodes only; all nodes participate in forward propagation. Trained with Adam optimizer, 200 epochs, L2 regularization ($\lambda = 5 \times 10^{-4}$), and sparse dropout (on input features and normalized attention coefficients).
- **Inductive capability:** Because attention weights are computed from node features (not from a precomputed graph spectrum), GAT can generalize to **unseen graphs** at test time — demonstrated on the PPI dataset where test graphs were not seen during training.
- **Toy graph dataset (Karate Club):** We use Zachary's Karate Club graph (34 nodes, 78 edges, 2 communities) for fast training and clear visualizations, with one-hot node identity features. The math is identical to the Cora experiments — only scale differs.

### What problem does it solve?

Imagine you're new at a school and you want to figure out which club each student belongs to — Drama Club or Science Club. You only know for sure about a few students (maybe the club presidents). But you do know who's friends with whom, and you can look at what each student is interested in (their hobbies, the books they carry).

Now, here's the thing: not all friends are equally helpful for figuring out someone's club. If your best friend is in Drama Club, that's a strong signal. But a random acquaintance you barely talk to? Less so. The problem with older methods (like GCN) is that they treat **every friend equally** — they average everyone's information the same way, just adjusting for how many friends someone has. It's like asking all 30 of your acquaintances for advice and giving every single one the exact same weight.

GAT fixes this by learning **who to pay attention to**. For each student, it automatically learns which friends' opinions matter most for determining their club. Maybe it learns that the student you eat lunch with every day is a much stronger signal than someone you just nod to in the hallway. It assigns an "attention score" to each friendship — higher for important friends, lower for casual ones — and uses those scores to make its prediction. And it learns these scores from the data itself, not by guessing!

This is incredibly useful beyond schools: predicting what products someone will like based on their social connections (where not all friends influence you equally), classifying proteins by function (where some interactions are more biologically significant than others), or detecting fraud in financial networks (where suspicious connections warrant more attention than routine ones).

### Influence

With over 30,000+ citations, the GAT paper is one of the most influential works in graph representation learning. It established **attention on graphs** as a fundamental paradigm, directly inspiring GATv2 (Brody et al., 2022), which addressed GAT's static attention limitation; Graph Transformers (Dwivedi & Bresson, 2020); and the broader family of attention-based GNNs. GAT is a core layer in PyTorch Geometric (`GATConv`), DGL, and TensorFlow GNN, making it one of the most-used GNN architectures in practice. The paper also bridged the gap between the attention mechanism (popularized by Bahdanau et al., 2015 and Vaswani et al., 2017 in NLP) and graph-structured data, showing that attention is a natural fit for irregular domains. GAT's inductive property was ahead of its time — it prefigored the inductive learning capabilities that became essential for real-world graph applications where new nodes and edges appear at test time. The attention visualizations in the paper (showing which neighbors receive high attention) also pioneered **GNN interpretability**, providing a built-in mechanism for understanding model decisions on graphs.
